Cleaned & Refined Messy Rows Dataset — View Repository↗

This Power Query project focused on cleaning and transforming messy, unstructured business data efficiently and effectively. It involved fixing duplicate columns, merged fields, and null values. Techniques like column splitting and unpivoting were used. This automated process handled repetitive tasks and saved significant time. The final output was a clean, structured dataset ready for accurate business analysis and reporting.

Hospital Emergency Room Dashboard — View Repository↗

My first Excel MIS Dashboard project analyzing Hospital ER performance. Built using Excel tools like Pivot Tables, Sparklines, Conditional Formatting, and Charts to track patient count, wait times, referrals, etc. It also helps identify trends and areas for improvement in emergency care. The dashboard provides clear visuals for faster decision-making. A hands-on project during my data analytics journey.

Analyzed 118.94K Nescafe sales (April 2023) using Power BI to uncover trends in product performance, store contributions, and customer behavior. Demonstrated how data-driven BI can optimize retail operations and support strategic decisions.

Motorola Sales Dashboard Analysis — View Repository↗

This interactive Power BI dashboard is specifically built for Motorola to monitor and analyze sales performance across multiple dimensions including city-wise trends, mobile model sales, payment methods, and customer satisfaction. NETFLIX Data SQL Analysis — View Repository↗

Analyzed a fictional NETFLIX dataset using PostgreSQL to uncover insights on movies, TV shows, genres, ratings, and countries. Using 15+ SQL queries, the project explored distribution, release trends, and diversity. It identified patterns in ratings, actors, and categories. The work demonstrates SQL skills in aggregation, filtering, and text search. Ultimately, it shows how SQL transforms data into actionable insights.

Blinkit Grocery Dashboard Analysis — View Repository↗

This project analyzes Blinkit’s grocery sales, customer satisfaction, and inventory trends using Power BI. With advanced DAX calculations, interactive slicers, and KPI visuals, it highlights top-performing products, outlet type trends, and growth opportunities.
